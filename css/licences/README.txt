Special Elite        Apache License 2.0, SpecialElite-LICENSE.txt.
                     Changed: subset to Basic Latin, digits and common punctuation, and

All three were downloaded from the Google Fonts repository on GitHub (google/fonts, folders
ofl/rye, ofl/imfellenglish, apache/specialelite) on 2026-11-13. Both licences allow the fonts
to be embedded in and redistributed with this game, with the licence text alongside.
